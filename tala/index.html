Geometric Progression in Tala

Each time a Carnatic performer moves from one speed to the next, the number of notes in every beat is multiplied by the same number. That is a geometric progression, and you can hear it.

Laya as a sequence

Laya is the speed of a tala. Each speed level is called a kalam. Going up one kalam multiplies the notes in each akshara (beat) by a fixed common ratio, r. Classically, r = 2: each kalam is twice as fast as the one before.

First terma = 1 note
Sum of the terms, Sn

an = a · rn−1

Sn = a(rn − 1) ÷ (r − 1)
